# Checklist — BadDev V 1.4, Fase 1 (terminal)

- [ ] Ver → Terminal, el botón `>_` y Ctrl+` abren y cierran el panel.
- [ ] BADDEV: `ayuda`, `ayuda buscar`, `ls`, `tree`, `cat index.html`, `buscar color` responden con el proyecto abierto.
- [ ] `imagenes` lista las imágenes de la carpeta abierta; `ls images` las muestra con 🖼.
- [ ] `abrir`, `nuevo pages/x.html`, `vista menu.html`, `tema toxic`, `zip` ejecutan la acción en el editor.
- [ ] Tab completa «ab» → «abrir » y nombres de archivo; flecha arriba repite; Ctrl+L limpia.
- [ ] Se puede cambiar el alto del panel arrastrando su borde superior.
- [ ] En `npm run dev` (web), la pestaña CMD REAL solo explica y avisa que requiere el .exe.
- [ ] En `npm run desktop:dev`: CMD REAL muestra la carpeta de Documentos y el aviso de permisos.
- [ ] ▣ cambia la carpeta de trabajo; `dir`, `cd ..`, `git status`, `node -v` muestran salida real.
- [ ] `ping -n 20 google.com` y luego Ctrl+C lo detiene.
- [ ] `ayuda dir` y `ayuda del` explican el comando real (del con aviso ⚠).
- [ ] Learn, Sandbox y la vista previa NO pueden usar la terminal real.

# Fase 2

- [ ] La barra superior muestra el botón **>_ Terminal**; se ilumina al abrir la terminal y se apaga al cerrarla.
- [ ] Learn → Lecciones: bajo los 12 lenguajes aparece «Aprender comandos». Abre 10 lecciones; los retos se comprueban y el progreso se guarda.
- [ ] Learn → Manual: «Leer comandos» muestra 10 secciones con puntos clave y errores frecuentes.
- [ ] Consola de la vista previa: los mensajes tienen hora y etiqueta; los filtros Errores/Avisos/Logs ocultan el resto; Copiar copia lo visible.
- [ ] Una página con `<img src="https://...">` ya no genera «Recurso bloqueado: img-src».
- [ ] Una página con `<script src="https://...">` sigue bloqueada.
